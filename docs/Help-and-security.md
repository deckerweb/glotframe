# Help and security

Questions and ideas: [Discussions](https://github.com/deckerweb/glotframe/discussions). Reproducible ordinary bugs: [Issues](https://github.com/deckerweb/glotframe/issues). Include WordPress, PHP, GlotPress and GlotFrame versions, steps, expected and actual results. Remove private content from screenshots.

Report vulnerabilities only through [private security reporting](https://github.com/deckerweb/glotframe/security/advisories/new). Never send credentials. See the [security policy](../SECURITY.md).
