# Hilfe und Sicherheit

Fragen und Ideen: [Discussions](https://github.com/deckerweb/glotframe/discussions). Reproduzierbare normale Fehler: [Issues](https://github.com/deckerweb/glotframe/issues). Nenne WordPress-, PHP-, GlotPress- und GlotFrame-Version, Schritte, erwartetes und tatsächliches Ergebnis. Entferne private Inhalte aus Screenshots.

Sicherheitslücken ausschließlich über [private Sicherheitsmeldungen](https://github.com/deckerweb/glotframe/security/advisories/new) melden. Keine Zugangsdaten senden. Details: [Sicherheitsrichtlinie](../SECURITY-de.md).
