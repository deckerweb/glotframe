# Security reporting

Do not disclose vulnerability details in public issues. Use [private reporting in the host repository](https://github.com/deckerweb/glotframe/security/advisories/new). If the repository is not yet public, use the private project contact through which you received the test package. Include GlotFrame, Library, updater, WordPress and PHP versions, reproduction steps and impact. Never include credentials.
